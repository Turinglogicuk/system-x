What happens when you press Decide

1
The model reads the message, the context and the numbered buttons once.
2
From that single pass it scores every button. If an action wins and is above τ, it stops there: no text, ~70 ms.
3
If REPLY_WITH_TEXT wins, or it isn't confident enough, it keeps going from the same memory and writes 1–2 lines.
